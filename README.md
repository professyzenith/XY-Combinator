## 🚀 Experience The Future of Video

XY Combinator is a state-of-the-art, entirely custom-built video conferencing platform. It strips away the bloat of traditional meeting software, leveraging the raw power of **Peer-to-Peer WebRTC** and **Supabase Realtime** to deliver instant, high-fidelity, and secure communication right in your browser.

## 🎮 Quick Start Guide

Want to run XY Combinator locally? Follow these steps to launch your own node.

### 1. Clone the repository
```bash
git clone https://github.com/professyzenith/XY-Combinator.git
cd XY-Combinator
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Set up Environment Variables
Create a `.env.local` file in the root directory and add your Supabase keys:
```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 4. Ignite the Engines
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) and watch the magic unfold! ✨
