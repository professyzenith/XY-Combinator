## 🌌 The Vision

Traditional video software is bloated, slow, and forces you to download desktop clients. **XY Combinator** strips away the friction. We leverage raw **Peer-to-Peer WebRTC** and **Supabase Realtime** to deliver instant, high-fidelity, and secure communication right in your browser.

## 🚀 Launch Sequence (Quick Start)

Deploy your own node of XY Combinator to your local machine in seconds.

<details>
<summary><b>Click to reveal setup instructions! 🛠️</b></summary>
<br/>

**1. Clone the repository**
```bash
git clone https://github.com/professyzenith/XY-Combinator.git
cd XY-Combinator
```

**2. Install Dependencies**
```bash
npm install
```

**3. Set up Environment Variables**
Create a `.env.local` file and add your keys:
```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

**4. Ignite the Engines**
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to enter the dashboard.
</details>
